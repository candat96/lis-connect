LIS Agent — cài đặt

Khai báo CSDL PostgreSQL dùng chung của LIS (cloud hoặc máy chủ tại viện). Các Agent ở các phòng xét nghiệm dùng chung một CSDL; mỗi Agent một tên riêng.

Trang cài đặt chỉ thao tác được trên chính máy cài Agent. Mở http://localhost:8090 tại máy đó.
Cơ sở dữ liệu
Agent này

Tên Agent phân biệt máy tính này với các phòng xét nghiệm khác: máy xét nghiệm và nhật ký gắn theo tên Agent.
