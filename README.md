# LIS Connect

Phần mềm trung gian (middleware) kết nối máy xét nghiệm, chạy độc lập hoặc tích hợp
hai chiều với HIS.

- Nhận chỉ định từ HIS, gửi xuống máy xét nghiệm (broadcast và host-query)
- Nhận kết quả từ máy, hiển thị, duyệt, trả về HIS hoặc in tại chỗ
- Theo dõi và ghi log kết nối tới từng máy xét nghiệm
- Cloud multi-tenant, mỗi cơ sở một database riêng
